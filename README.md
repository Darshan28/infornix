## SEO / launch checklist

Site meta, JSON-LD, sitemap, and robots use production origin **`https://infornix.vercel.app`** (temporary until a custom domain is purchased).

When you switch to a custom domain, replace every `https://infornix.vercel.app` in:

- `index.html` (canonical, Open Graph, JSON-LD)
- `public/robots.txt`
- `public/sitemap.xml`
- `public/llms.txt`
- `src/site.ts`

After deploy:

1. [Google Search Console](https://search.google.com/search-console) — add **infornix.vercel.app**, verify, submit `https://infornix.vercel.app/sitemap.xml`
2. [Google Business Profile](https://business.google.com/) — claim “Infornix Technologies” with the same NAP (name, address, phone)
3. [Bing Webmaster Tools](https://www.bing.com/webmasters) — submit sitemap
4. Share the site + GBP URL for branded mentions (LinkedIn, maps citations)

Brand queries (`Infornix`, `Infornix Technologies`) index fastest after Search Console + stable domain. Broad terms (`IT Hardware`, `IT Solutions`) need local GBP strength and ongoing reviews.
